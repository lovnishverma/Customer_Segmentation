Understanding Unsupervised Learning & K-Means Clustering

Supervised vs Unsupervised Learning
🌸 Supervised Learning (Iris)
  • Data has labels (Setosa, Versicolor, Virginica)
  • Model learns from examples
  • Goal: Predict the class
  • Algorithms: SVM, Decision Tree, KNN
  • Evaluation: Accuracy, Precision, Recall
🛍️ Unsupervised Learning (This Project)
  • Data has NO labels
  • Model finds patterns on its own
  • Goal: Discover hidden groups
  • Algorithms: K-Means, DBSCAN, Hierarchical
  • Evaluation: Silhouette Score, Elbow Method
How K-Means Algorithm Works
1
Initialize
Randomly place K centroids in the data space
2
Assign
Assign each data point to the nearest centroid
3
Update
Move each centroid to the mean of its assigned points
4
Repeat
Repeat steps 2–3 until centroids stop moving
5
Converge
Algorithm converges to stable cluster assignments
✓
Predict
Assign new data to the nearest cluster centroid
