# 🛍️ Customer Segmentation — Unsupervised ML
### The "Hello World" of Unsupervised Machine Learning

---

## 🎯 Project Overview

| | Supervised (Iris) | Unsupervised (This Project) |
|---|---|---|
| **Concept** | Classification | Clustering |
| **Labels** | ✅ Given | ❌ Not needed |
| **Algorithm** | Decision Tree / SVM | K-Means |
| **Output** | Predict flower species | Discover customer groups |
| **Evaluation** | Accuracy, F1-Score | Elbow Method, Silhouette |

## 🚀 Step-by-Step Setup

### Step 1: Train the Model (Google Colab)

1. Open **Google Colab**: https://colab.research.google.com
2. Upload `Customer_Segmentation_Training.ipynb`
3. Run all cells (Runtime → Run All)
4. Download the generated files:
   - `kmeans_model.pkl`
   - `scaler.pkl`

### Step 2: Place Model Files

Put the downloaded files in the `model/` folder:
```
customer_segmentation/
└── model/
    ├── kmeans_model.pkl   ← paste here
    └── scaler.pkl         ← paste here
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Run the Flask App

```bash
python app.py
```

### Step 5: Open in Browser

```
http://127.0.0.1:5000
```

## 🧠 ML Concepts Covered

- **Unsupervised Learning** — finding patterns without labels
- **K-Means Clustering** — iterative centroid-based grouping
- **Elbow Method** — choosing the optimal number of clusters (K)
- **Silhouette Score** — measuring cluster quality
- **Feature Scaling** — StandardScaler for distance-based algorithms
- **Model Persistence** — saving/loading with joblib

## 👨‍🏫 For Educators

This project is designed to mirror the Iris classification project for supervised learning.

**Teaching Progression:**
1. Start with Iris (supervised) → students understand labelled data
2. Introduce this project → students see what happens WITHOUT labels
3. Compare the workflows side-by-side
4. Discuss real-world use cases: recommendation systems, anomaly detection, image segmentation

**Discussion Questions:**
- Why can't we use accuracy to evaluate K-Means?
- What happens if we pick K=2? K=10?
- Why do we scale features before K-Means?
- Can you think of other real-world clustering applications?
